Cancer 10°

原文

完全にはカットされていない大きなダイヤモンド

解読

このシンボルでは、完全にはカットされていない大きなダイヤモンドが描かれている。

これは、まだ何の加工もされていない原石ではない。カットはすでに始まっている。しかし、まだ完成していない。

そして、それは大きなダイヤモンドである。ダイヤモンドはカットされる前からダイヤモンドであり、すでに価値を持っている。しかも大きな石であれば、もともと持っている価値も大きい。

しかし、その大きな石をどのようにカットするかによって、最終的に現れる形や輝きは変わってくる。

カットとは、何かを付け加える作業ではない。石の一部を削ぎ落としていく作業である。削れば、石そのものは小さくなる。

それでも、適切に削ぎ落とされることで面が生まれ、光を受ける形が整い、もともとダイヤモンドが持っていた価値が別の形で現れてくる。

つまり、減ることがそのまま価値を失うことにはならない。何を残し、何を削ぎ落とすかによって、すでに存在していた大きな価値が、さらに価値のある形へと変わっていく。

ただし、このダイヤモンドはまだ完成していない。価値がないから未完成なのではない。すでに大きな価値を持ちながら、その価値をどのような形で現すのかが、まだ決まりきっていないのである。

一文で表すなら

「すでにある大きな価値は、削ぎ落とすことで、さらに価値ある形へと変わっていく。」

Original Text

A large diamond not completely cut

Deciphering

In this symbol, a large diamond is shown that has not been completely cut.

This is not a rough stone that has never been worked on. The cutting has already begun, but it is not yet complete.

And it is a large diamond. A diamond is already a diamond before it is cut, and it already possesses value. If the stone is large, the value it originally holds is also great.

However, the final shape and brilliance that appear will depend on how this large stone is cut.

Cutting is not a process of adding something. It is a process of removing parts of the stone. As it is cut, the stone itself becomes smaller.

Even so, when the right parts are removed, facets are created, the stone takes a form that can receive and reflect light, and the value that was already within the diamond begins to appear in a different form.

In other words, becoming smaller does not necessarily mean losing value. What is kept and what is removed can transform the great value that already exists into an even more valuable form.

However, this diamond is still unfinished. It is not unfinished because it lacks value. It already possesses great value, but the form through which that value will ultimately appear has not yet been fully determined.

In one sentence

“Great value that already exists can become even more valuable in form through the process of cutting away.”

解讀

一顆尚未完全切割的大鑽石。

在這個象徵中，出現了一顆尚未完全切割的大鑽石。

這並不是一顆完全沒有經過加工的原石。切割已經開始了，只是還沒有完成。

而且，這是一顆大鑽石。鑽石在被切割之前就已經是鑽石，本身已經具有價值。如果是一顆很大的鑽石，它原本所擁有的價值也很大。

但是，這顆大鑽石最終會呈現出什麼樣的形狀與光芒，取決於它將如何被切割。

切割並不是增加什麼東西的過程，而是將石頭的一部分削去。隨著切割進行，鑽石本身會變得更小。

即使如此，透過適當地削去一部分，鑽石會形成不同的切面，逐漸成為能夠接收並反射光線的形狀，原本就存在於鑽石中的價值，也會以另一種形式呈現出來。

也就是說，減少並不等於失去價值。選擇留下什麼、削去什麼，可以讓原本就存在的巨大價值，轉變成更加具有價值的形態。

但是，這顆鑽石現在仍然尚未完成。它並不是因為沒有價值才尚未完成，而是在已經擁有巨大價值的情況下，那份價值最終要以什麼樣的形態呈現，還沒有完全確定。

用一句話來說

「原本就存在的巨大價值，可以透過削去一部分，轉變成更加具有價值的形態。」
